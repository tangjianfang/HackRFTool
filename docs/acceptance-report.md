## 二、选项规范性 review（广播/无线通信规范对照）

| 选项 | 现值 | 规范对照 | 结论 |
|---|---|---|---|
| 采样率 | 2/8/10/16/20 Msps | HackRF One 支持 2-20Msps（偶数档）；窄带用低档、全频段用 20 | ✅ |
| LNA | 8-40dB 步进 8 | HackRF 官方 0/8/16/24/32/40（0=关闭不实用） | ✅ |
| VGA | 2-62dB 步进 2 | HackRF 官方 0-62 偶数 | ✅ |
| 功放 | 开/关 | 板载 PA +14dB | ✅ |
| 收听带宽 | ±120/±80/±50 kHz | FM 广播信道 200kHz（±100k 理想，±120k 含保护带可用）；±50k 适配 NOAA APT(35kHz) | ✅（±80k 为过渡档） |
| 收音频率 | clamp 24-1800 | FM 广播 87.5-108（中国/ITU Region 3）；NOAA 137-138 | ✅（宽 clamp 供卫星/其它业务） |
| 卫星预设 | 137.100/137.620/137.9125 | NOAA 19/15/18 官方 APT 下行 | ✅ |
| 符号率 | 1/2 Mbps | ESB/GFSK 2.4G 常用 | ✅ |
| 频谱窗 | 中心±采样率/2 | 基带有效带宽 | ✅ |
