1. Overview

HackRFTool 是运行于 Windows x64 的单进程桌面应用，通过 HackRF One 硬件接收 2.4 GHz ISM 频段信号（nRF24 ESB 私有协议 / BLE 蓝牙广播），并覆盖 FM 广播收音、NOAA/Meteor 气象卫星云图接收、轨道预测。本文档覆盖：系统架构（含线程/数据流/契约）、RF 基础知识（小白到入门）、HackRF 使用与天线选择。合规边界：只收不发。

15. RF 基础知识（小白到入门）

15.1 频率、波长与频段

无线电波以频率（Hz）区分。波长 λ = 光速 c ÷ 频率 f——这个数决定天线长度：天线要"谐振"于目标频率，最常用 λ/4（四分之一波长）。例如 FM 100MHz 的 λ/4 ≈ 75cm，而 2.4GHz 只有 ≈ 3.1cm。

本工具涉及的频段频率范围λ/4 天线长度常见信号
FM 广播87.5–108 MHz≈ 70–80 cm电台（立体声导频 19kHz）
NOAA/Meteor 气象卫星137–138 MHz≈ 54 cmAPT 模拟云图 / LRPT 数字云图
2.4 GHz ISM2400–2483.5 MHz≈ 3.1 cmnRF24 ESB（鼠标键盘）、BLE 蓝牙、WiFi
BLE 广播信道2402 / 2426 / 2480 MHz（37/38/39）同上设备名广播包（每 20ms–10s 一发）

15.2 采样率与带宽（奈奎斯特）

数字接收机不能直接"听"模拟信号，要按一定速率采样。采样率必须 ≥ 想看的带宽的 2 倍（奈奎斯特）。本工具里采样率的实际意义：

采样率档位能看的频谱窗宽典型用途代价
2 Msps±1 MHz（2MHz 窗）收音音频链（FM 通道带宽 250k）CPU/USB 最省
8–16 Msps±4–8 MHzBLE 解调（符号定时精度需要）中等
20 Msps±10 MHz（够 ESB 符号定时 + 全频段 5 段拼接）ESB 抓包/全频段扫描USB/CPU 满负荷

这也是为什么软件在收音时强制 2Msps、BLE 时强制 16Msps、全频段强制 20Msps（ADR-005）——不是随意的，是子链的物理需要。

15.3 dB / dBm / dBFS：别怕对数单位

单位含义本工具哪里出现
dB比值（差多少倍）峰均差 >8dB 判有台（静噪门限）
dBm绝对功率（0dBm=1mW）信号强度惯例单位（信号库列表）
dBFS相对满量程（0=最大，负数）频谱纵轴、突发峰值（127 满幅=0dBFS）

口诀：每 ±6dB ≈ 功率 ±4 倍（电压 ±2 倍）；dB 只能"相减做比较"，说"信号是 -60dB"其实是 -60dBm 的简称。

15.4 IQ 采样：一台设备为什么叫"软件无线电"

HackRF 输出的不是"音频"也不是"电压波形"，而是 I/Q 两路（同相/正交）——把中心频率附近的整段频谱"搬"到基带记录下来。中心频率由你设定，I/Q 数据里包含了这段窗内所有信号。所以"换个频率抓"= 改中心频率（热切，毫秒级），"换个协议解"= 对同一份 IQ 用不同解调器。本工具的 burst 检测→GFSK→ESB/BLE 全部发生在 IQ 之后。

15.5 数字调制：本工具四类信号怎么" encoded "

信号调制方式速率帧结构要点工具内解析器

GFSK 是什么：用"频率偏正/偏负"表示 0/1。解调器把每个符号的瞬时频率判成正/负即恢复比特。难点在符号时钟对齐（本工具用多相位试解+AA 图案评分）和频偏校准。BLE 还要对载荷做"白化"搅频（每个信道一种伪随机序列），这就是为什么约定错了 CRC 永远不过——#109 攻坚正是靠离线穷举破解了这个约定。

15.6 噪底、信噪比与"为什么我全是噪声"

  • 噪底：没有信号时频谱的底线。天线越差/增益越不合理，噪底相对越高。
  • 信噪比 SNR：信号峰高出噪底的 dB 数。数字解调要求 SNR 足够高——BLE 包 CRC 过不过，本质就是全帧累积误码是否 <0.5%。
  • 增益三级：AMP（板载功放，开=更灵敏但易饱和）→ LNA（低噪放 0–40dB，主力）→ VGA（基带 0–62dB，兜底）。调法：先 LNA 上到信号刚出现，再 VGA 微调；增益过高会饱和——表现为突发时长全接近 100ms 连片（工具会在抓包页提示你降 LNA/VGA）。
  • 静噪（Squelch）：收音时"没信号就静音"的守门员。本工具用双条件（峰均差>8dB 且峰值>−55dB），防噪声台假开门。

17. 抓不同信号要不要换天线？（要，看这张表）

天线 = 谐振器 + 方向器。两个原则：① 长度匹配波长（λ/4 起步）；② 频段对上（2.4G 天线收 FM 效率极低，反之亦然）。本工具四类目标的天线建议：
