## 排障记录（本里程碑最重要的发现）

1. **`animate_for(100)` 心跳窗口自灭（builds=1 玄学的总根因）**：WinFlux 的动画心跳机制是"每次 build 续期"；首帧冷启动（D2D/字体初始化）偶尔超 100ms，动画期限在首个 WM_TIMER 前过期 → `handle_timer` 判无需求 → **KillTimer 永久熄火**。M1 瀑布单行、M5 系列偶发、M6 间歇失败同源。修复：窗口 100ms → 400ms（常态行为不变，抗住冷启动卡顿）
2. **合成信号若载波在 DC 会落进分析器边缘裁剪带**：512 点复 FFT 中 DC 在 bin 0、负频在 257-511，分析器为硬件基带跌落裁掉的恰是数组两端——合成测试信号必须搬移到带内（本测试 +2.5 MHz）
3. 消息循环启动前对窗口做 SetForegroundWindow/ALT 注入会把渲染循环搞挂——自动化激活必须在循环运行后、且由非 UI 线程发起（若仍不稳定则靠 1 的根因修复即可，M6 最终未依赖激活）
4. 整机自测必须跑 Release 配置（`ctest --preset x64-release`）：Debug 的全量 FFT 会 CPU 饥饿（M4 教训的回归验证）
